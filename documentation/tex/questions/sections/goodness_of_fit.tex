\notebook{07-goodness-of-fit}
The questions of this section concern the compensator of Definition~\ref{notes:def.compensator},
its closed form for the exponential kernel, Proposition~\ref{notes:prop.compensatorClosedForm},
and the test of goodness of fit that Theorem~\ref{notes:thm.meyer1971} makes of it,
Section~\ref{notes:sec.simulation}.
The two types are read as the market buys, type 0, and the market sells, type 1,
as the arrays of the package index them.
The pairs of \codehl{config} have $\decay = 4$.
The self-exciting pair has $\baseIntensity = (0.25, 0.25)$,
$\excitation = ((2.8, 0.2), (0.2, 2.8))$ row by row,
$\branchingRatio = 0.75$ and $\stationaryIntensity = (1, 1)$.

The function \codehl{compensators\_at\_events(params, times, types)} of \codehl{unito26.lob.hawkes}
returns an array whose row $k$ is $\compensator(\arrivalTimes[ ]_k)$,
by equation~\eqref{notes:eq.compensatorClosedForm},
with the count read before $\arrivalTimes[ ]_k$ and the state at it.
The residuals of a type are the increments~\eqref{notes:eq.time-changed_intertimes}
of its own compensator between its own arrivals, the first counted from $\compensator(0) = 0$.
\codehl{stats} is \codehl{scipy.stats}.
\codehl{stats.kstest(x, cdf)} compares the sample \codehl{x} with the law whose distribution function is \codehl{cdf},
and \codehl{stats.kstest(x, "expon")} compares it with $\mathrm{Exp}(1)$:
its \codehl{statistic} is the largest distance $D$ between the empirical distribution function and \codehl{cdf},
and its \codehl{pvalue} is the p-value of the test.

\begin{question}
\label{question.palmMeanOfTheTotalIntensity}
A check of a simulator compares the mean of the total intensity
$\totalIntensity = \mathbf{1}^{\transpose}\intensity[ ]$ with the total rate $\totalRate$,
reading the intensity at the events of a long path of the self-exciting pair
with the function quoted below.
The column sums of $\excitation$ are both 3,
so that $\totalIntensity = 0.5 + 3 \, \mathbf{1}^{\transpose}\decayedCounts$,
and by equation~\eqref{notes:eq.scalarVariance}
the stationary variance of $\mathbf{1}^{\transpose}\decayedCounts$ is
$\totalRate / (2\decay(1-\branchingRatio)) = 1$.
\begin{lstlisting}[caption={\protect\codehl{unito26.lob.hawkes.intensities\_at\_events}, its docstring elided.}, label=listing.palmIntensitiesAtEvents]
def intensities_at_events(
    params: HawkesParams, times: np.ndarray, types: np.ndarray
) -> np.ndarray:
# ...
    beta = params.decay

    decayed = np.zeros(params.dimension)
    previous_time = 0.0
    out = np.empty((times.size, params.dimension))

    for k, (time, event_type) in enumerate(zip(times, types)):
        decayed *= np.exp(-beta * (time - previous_time))
        out[k] = params.baseline + params.excitation @ decayed
        decayed[event_type] += 1.0
        previous_time = time

    return out
\end{lstlisting}
\begin{lstlisting}[caption={The total intensity at the events, before and after the jump}, label=listing.palmMeanRun]
params = config.self_exciting_pair_params()
path = np.array(list(ExponentialHawkes(params, rng=3).events(4e4)))
times, types = path[:, 0], path[:, 1].astype(int)
before = intensities_at_events(params, times, types).sum(axis=1)
after = before + params.excitation.sum(axis=0)[types]
print(round(len(times) / 4e4, 1), round(before.mean(), 1),
      round(after.mean(), 1))
\end{lstlisting}

\begin{choices}
 \choice \codehl{2.0 2.0 5.0}
 \correctchoice \codehl{2.0 6.5 9.5}
 \choice \codehl{2.0 2.5 5.5}
 \choice \codehl{2.0 4.5 7.5}
\end{choices}
\explanation{By equation~\eqref{notes:eq.compensators_and_predict_projections}
with the predictable $Y = \totalIntensity$,
the sum of $\totalIntensity(\arrivalTimes[ ]_n)$ over the events has the mean of $\int \totalIntensity^2 \, dt$,
so the mean over the events is
$\Expectation[\totalIntensity^2]/\totalRate = (9 \cdot 1 + 2^2)/2 = 6.5$:
an event arrives where the intensity is high.
The clock gives $\totalRate = 2$,
and after the jump each reading gains the column sum 3.}
\end{question}

\begin{question}
\label{question.compensatorReadAfterTheJump}
The package evaluates the compensator at the events by the recursion below:
\codehl{decayed} is the state $\decayedCounts$ and \codehl{counts} the count $\multiCountingProc$,
both updated after row $k$ is recorded.
Alternatives B and C move the record past one update or both.
\begin{lstlisting}[caption={\protect\codehl{unito26.lob.hawkes.compensators\_at\_events}, its docstring elided.}, label=listing.compensatorsAtEventsQuote]
def compensators_at_events(
    params: HawkesParams, times: np.ndarray, types: np.ndarray
) -> np.ndarray:
# ...
    d = params.dimension
    beta = params.decay

    decayed = np.zeros(d)  # Z, decayed to just before the current event
    counts = np.zeros(d)  # N, events strictly before the current one
    previous_time = 0.0
    out = np.empty((times.size, d))

    for k, (time, event_type) in enumerate(zip(times, types)):
        decayed *= np.exp(-beta * (time - previous_time))
        out[k] = params.baseline * time + params.excitation @ ((counts - decayed) / beta)
        decayed[event_type] += 1.0
        counts[event_type] += 1.0
        previous_time = time

    return out
\end{lstlisting}
\begin{lstlisting}[caption={Alternative B}, label=listing.compensatorReadAfterBoth]
def compensators_b(params, times, types):
    mu, A, beta = params.baseline, params.excitation, params.decay
    decayed, counts = np.zeros(2), np.zeros(2)
    previous, out = 0.0, np.empty((times.size, 2))
    for k, (time, event_type) in enumerate(zip(times, types)):
        decayed *= np.exp(-beta * (time - previous))
        decayed[event_type] += 1.0
        counts[event_type] += 1.0
        out[k] = mu * time + A @ (counts - decayed) / beta
        previous = time
    return out
\end{lstlisting}
\begin{lstlisting}[caption={Alternative C}, label=listing.compensatorReadAfterTheCount]
def compensators_c(params, times, types):
    mu, A, beta = params.baseline, params.excitation, params.decay
    decayed, counts = np.zeros(2), np.zeros(2)
    previous, out = 0.0, np.empty((times.size, 2))
    for k, (time, event_type) in enumerate(zip(times, types)):
        decayed *= np.exp(-beta * (time - previous))
        counts[event_type] += 1.0
        out[k] = mu * time + A @ (counts - decayed) / beta
        decayed[event_type] += 1.0
        previous = time
    return out
\end{lstlisting}

\begin{question}
\label{question.compensatorByRecursionSumOrQuadrature}
Three implementations of the compensator at the events are compared.
Alternative A is the function of the package
quoted in Question~\ref{question.compensatorReadAfterTheJump}.
Alternative B sums,
for each $\arrivalTimes[ ]_k$,
the integral of the proof of Proposition~\ref{notes:prop.compensatorClosedForm}
over the events before it.
Alternative C integrates the intensity numerically between consecutive events:
\codehl{quad\_vec(f, a, b)} of \codehl{scipy.integrate} returns the integral of a vector-valued \codehl{f}
over $(a, b)$ and an estimate of its error,
by adaptive Gauss--Kronrod quadrature,
evaluating \codehl{f} at 21 points of every subinterval it makes.
\begin{lstlisting}[caption={Alternative B}, label=listing.compensatorBySum]
def compensators_by_sum(params, times, types):
    mu, A, beta = params.baseline, params.excitation, params.decay
    out = np.empty((times.size, 2))
    for k, time in enumerate(times):
        mass = (1 - np.exp(-beta * (time - times[:k]))) / beta
        out[k] = mu * time + A[:, types[:k]] @ mass
    return out
\end{lstlisting}
\begin{lstlisting}[caption={Alternative C}, label=listing.compensatorByQuadrature]
def compensators_by_quadrature(params, times, types):
    mu, A, beta = params.baseline, params.excitation, params.decay
    state, total, previous = np.zeros(2), np.zeros(2), 0.0
    out = np.empty((times.size, 2))
    for k, (time, event_type) in enumerate(zip(times, types)):
        def intensity(u):
            return mu + A @ state * np.exp(-beta * (u - previous))
        total = total + quad_vec(intensity, previous, time)[0]
        out[k] = total
        state = state * np.exp(-beta * (time - previous))
        state[event_type] += 1.0
        previous = time
    return out
\end{lstlisting}
The three agree to rounding.
They are timed on the first $n$ events of one path of the self-exciting pair,
for $n = 2000$, 4000, 8000 and 16000.
Which statement holds?
\begin{choices}
 \choice C is the fastest at $n = 16000$, \codehl{quad\_vec} running compiled code.
 \choice The time of each of the three about doubles with each doubling of $n$.
 \choice The times of A and B about double with each doubling of $n$,
  and that of C about quadruples.
 \correctchoice At $n = 16000$ A is faster than B and than C by more than fivefold;
  the times of A and C about double with each doubling of $n$,
  and that of B grows more than threefold.
 \choice B is the fastest, its sum over the past being vectorised,
  and the time of A about quadruples with each doubling of $n$.
\end{choices}
\explanation{A carries the state from event to event at a constant cost.
B sums over every earlier event, so event $k$ costs a time proportional to $k$, and the path a time quadratic in $n$.
C carries the state too, and its cost per event is constant,
but each interval costs a call of the integrator and its evaluations of the intensity,
of the order of a hundred steps of A.}
\end{question}

\begin{question}

 \correctchoice The first is well above $0.01$, the second about $0.01$.
 \choice Both are well above $0.01$.
 \choice The first is about $0.01$, the second well above it.
\end{choices}
\explanation{Under both specifications the two simulators draw the same law,
and a test at its level rejects about once in a hundred.
The gaps of a Poisson flow are independent.
The gaps along one path of the self-exciting pair are dependent,
so the gaps of one path vary from path to path more than a sample of independent gaps would,
and the test overstates its evidence;
one statistic per independent path restores the level.}
\end{question}
