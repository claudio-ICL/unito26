\notebook{05-inheritance}
The questions of this section concern Appendix~\ref{notes:chap.objectOrientedProgramming}.
Most of them are asked of the five books of Section~\ref{notes:sec.fasterBook}:
\codehl{AggregateBook} and its four subclasses
\codehl{CachedBestBook}, \codehl{HeapBook}, \codehl{BitmapBook} and \codehl{TickArrayBook},
of \codehl{unito26.lob.orderbook},
which inherit its matching
and override how a side is stored and how its best price is found.

\begin{question}

 \choice \codehl{936 139 936 139}

\begin{question}
\label{question.bypassedWritesOnThreeBooks}
\codehl{CachedBestBook} and \codehl{HeapBook} keep the two dictionaries of \codehl{AggregateBook}
as their storage, and beside them an index of the best price, which their \codehl{set\_size} maintains.
\codehl{from\_levels} writes every level through \codehl{set\_size},
and the property \codehl{best\_bid\_price} returns \codehl{self.best\_price(BUY)}.
In \codehl{HeapBook}, \codehl{heapq.heappush} adds an entry to a list kept as a heap,
whose least entry is \codehl{heap[0]},
and \codehl{heapq.heappop} removes that entry.
\begin{lstlisting}[caption={\protect\codehl{unito26.lob.orderbook.CachedBestBook}, abridged: its docstrings and comments are cut.}, label=listing.bypassedWritesOnThreeBooksCached]
class CachedBestBook(AggregateBook):
    # ...
    def __init__(self, strict: bool = False):
        super().__init__(strict)
        self._cached: dict[int, int | None] = {BUY: None, SELL: None}

    def set_size(self, direction: int, price: int, size: int) -> None:
        super().set_size(direction, price, size)
        self._cached[direction] = self._best_after(direction, price, size)

    def _best_after(self, direction: int, price: int, size: int) -> int | None:
        # ...
        best = self._cached[direction]
        # ...
        if size > 0 and (best is None or price * direction > best * direction):
            return price
        if size == 0 and price == best:
            # ...
            return self._rescan(direction)
        # ...
        return best

    def _rescan(self, direction: int) -> int | None:
        levels = self.levels_map(direction)
        if not levels:
            return None
        return max(levels) if direction == BUY else min(levels)

    def best_price(self, direction: int) -> int | None:
        return self._cached[direction]
\end{lstlisting}
\begin{lstlisting}[caption={\protect\codehl{unito26.lob.orderbook.HeapBook}: the constructor, the write and the best price, a comment cut.}, label=listing.bypassedWritesOnThreeBooksHeap]
def __init__(self, strict: bool = False):
    super().__init__(strict)
    self._heaps: dict[int, list[int]] = {BUY: [], SELL: []}

def set_size(self, direction: int, price: int, size: int) -> None:
    super().set_size(direction, price, size)
    if size > 0:
        # ...
        heapq.heappush(self._heaps[direction], -price if direction == BUY else price)

def best_price(self, direction: int) -> int | None:
    heap = self._heaps[direction]
    levels = self.levels_map(direction)
    while heap:
        price = -heap[0] if direction == BUY else heap[0]
        if price in levels:
            return price
        heapq.heappop(heap)  # stale entry: the level is gone
    return None
\end{lstlisting}
The snippet writes to the bid dictionary of each book directly.
\begin{lstlisting}[caption={Two writes past \protect\codehl{set\_size}}, label=listing.bypassedWritesOnThreeBooksRun]
prices = []
for cls in (AggregateBook, CachedBestBook, HeapBook):
    book = cls.from_levels({99: 100, 98: 50}, {101: 100})
    book.bids[100] = 50
    del book.bids[99]
    prices.append(book.best_bid_price)
print(prices)
\end{lstlisting}
What does the snippet print?
\begin{choices}
 \choice \codehl{[100, 100, 100]}
 \choice \codehl{[100, 99, 100]}
 \choice \codehl{[100, 99, 99]}
 \correctchoice \codehl{[100, 99, 98]}
 \choice \codehl{[100, 98, 98]}
\end{choices}
\explanation{The two writes bypass \codehl{set\_size}, and with it the index of each subclass,
against hypothesis \emph{iii.} of Proposition~\ref{notes:prop.invariantByInduction}.
The plain book scans its dictionary and finds 100; the cache still holds 99,
a price no longer in the book.
The heap holds 99 and 98 and not 100:
lazy deletion discards the stale 99, and nothing has told the heap of 100.}
\end{question}

\begin{question}
\label{question.lookupsCountedThroughTheInheritedMatching}
The subclass below counts the calls of \codehl{best\_price}.
The class method \codehl{from\_levels} creates the book by calling \codehl{cls(strict)},
writes every level through \codehl{set\_size},
and ends by calling \codehl{check\_invariants},
which reads the properties \codehl{best\_bid\_price} and \codehl{best\_ask\_price} once each;
they return \codehl{self.best\_price(BUY)} and \codehl{self.best\_price(SELL)}.
\codehl{apply} passes an order to \codehl{submit}, quoted below.
A market buy carries a price above every price of the book,
and for a market order \codehl{resting\_price} returns \codehl{last\_fill\_price}:
what is left of it rests at the price it last traded at.
\begin{lstlisting}[caption={\protect\codehl{unito26.lob.orderbook.AggregateBook.submit}, abridged: the recording of fills and of level changes is cut.}, label=listing.lookupsCountedThroughTheInheritedMatchingSubmit]
def submit(self, message: Message, record: bool) -> SubmitResult | None:
    # ...
    remaining = message.size
    direction = message.direction
    limit_price = message.price
    # ...
    last_fill_price = None
    # ...
    while remaining > 0:
        best = self.best_price(-direction)
        # ...
        if best is None or best * direction > limit_price * direction:
            break
        resting = self.size_at(-direction, best)
        traded = min(remaining, resting)
        remaining -= traded
        self.set_size(-direction, best, resting - traded)
        # ...
        last_fill_price = best
    # ...
    rest_price = self.resting_price(limit_price, last_fill_price)
    if remaining > 0 and rest_price is not None:
        resting = self.size_at(direction, rest_price) + remaining
        self.set_size(direction, rest_price, resting)
\end{lstlisting}
\begin{lstlisting}[caption={A book that counts its lookups}, label=listing.lookupsCountedThroughTheInheritedMatchingClass]
class CountingBook(AggregateBook):
    def __init__(self, strict):
        super().__init__(strict)
        self.lookups = 0

    def best_price(self, direction):
        self.lookups += 1
        return super().best_price(direction)
\end{lstlisting}
\begin{lstlisting}[caption={Two market buys}, label=listing.lookupsCountedThroughTheInheritedMatchingRun]
book = CountingBook.from_levels({99: 100}, {101: 100, 102: 80, 105: 20})
stream = [market_order(1.0, 190, BUY), market_order(2.0, 40, BUY)]
counts = [book.lookups]
for message in stream:
    book.apply(message, record=False)
    counts.append(book.lookups)
print(counts, book.best_bid_price)
\end{lstlisting}
What does the snippet print?
\begin{choices}
 \choice \codehl{[0, 3, 5] 105}
 \choice \codehl{[0, 0, 0] 105}
 \choice \codehl{[2, 5, 6] 105}
 \choice \codehl{[2, 5, 7] 99}
 \correctchoice \codehl{[2, 5, 7] 105}
\end{choices}
\explanation{Every \codehl{self.best\_price} of the inherited code, that of the check included,
is the override, Proposition~\ref{notes:prop.lateBinding}: two lookups before any order.
The buy of 190 looks up 101, 102 and 105, and stops when nothing remains.
The buy of 40 takes the 10 left at 105, looks up an empty side, and rests 30 at 105 on the bid.}
\end{question}

\begin{question}
\label{question.indexedBookWithoutSuper}
The subclass below keeps the occupied prices of each side in a set, and finds its best prices there.
It is completed by one of two definitions of \codehl{set\_size}.
\codehl{best\_bid\_size} returns \codehl{size\_at(BUY, p)} at the best bid $p$,

The matching is that of Listing~\ref{listing.lookupsCountedThroughTheInheritedMatchingSubmit},
and \codehl{last\_traded\_size} is the number of shares the last message traded.
\begin{lstlisting}[caption={A book that indexes its prices in a set}, label=listing.indexedBookWithoutSuperClass]
class IndexedBook(AggregateBook):
    def __init__(self, strict):
        super().__init__(strict)
        self.occupied = {BUY: set(), SELL: set()}

    def best_price(self, direction):
        prices = self.occupied[direction]
        if not prices:
            return None
        return max(prices) if direction == BUY else min(prices)
\end{lstlisting}
\begin{lstlisting}[caption={Alternative A}, label=listing.indexedBookWithoutSuperA]
    def set_size(self, direction, price, size):
        super().set_size(direction, price, size)
        if size > 0:
            self.occupied[direction].add(price)
        else:
            self.occupied[direction].discard(price)
\end{lstlisting}
\begin{lstlisting}[caption={Alternative B}, label=listing.indexedBookWithoutSuperB]
    def set_size(self, direction, price, size):
