\begin{frame}
  \frametitle{The intensity is a rate given the strict past}
\[
 \Expectation\big[ \countingProc(t) - \countingProc(s) \,\big|\, \filtrationF_s \big]
 = \Expectation\Big[ \int_{s}^{t} \intensity(u) \, du \,\Big|\, \filtrationF_s \Big],
 \qquad
 \compensator_e(t) = \int_{0}^{t} \intensity(u)\,du
\]

$\intensity$: predictable, a function of the strict past

$\multiCountingProc - \compensator$: a local martingale
\note{
A $\numEventTypes$-dimensional counting process $\multiCountingProc$ counts the events of each
type; its ground process $\groundProc$ counts all of them, and the labels $\event[n]$ say which
type the $n$-th event is. No two components jump together.
The compensator is the predictable process that turns $\multiCountingProc$ into a martingale,
and when it is absolutely continuous its density is the intensity: the instantaneous rate of
an event of each type, given what has been observed so far. Predictability is the whole
content --- the intensity at $t$ is a function of the past strictly before $t$, which is why
every intensity we write is left-continuous.
}
\end{frame}

\begin{frame}
  \frametitle{The next wait has a survival function we can invert}
\[
 \Prob\big( \arrivalTimes[ ]_{n+1} - \arrivalTimes[ ]_{n} > s
 \,\big|\, \filtrationF_{\arrivalTimes[ ]_{n}} \big)
 = \exp\Big( - \int_{\arrivalTimes[ ]_{n}}^{\arrivalTimes[ ]_{n}+s}
 \totalIntensity(u) \, du \Big)
\]

$\totalIntensity = \intensity[1] + \dots + \intensity[\numEventTypes]$: the ground intensity,
on the event of no arrival

Poisson: $e^{-\totalIntensity s}$
\note{
With respect to the internal history, on the event that no arrival occurs the integrand is a
deterministic function of the history up to $\arrivalTimes[ ]_{n}$, so the right-hand side is
known at $\arrivalTimes[ ]_{n}$ and is a genuine survival function.
Both simulators of the third part are this proposition: thinning runs it backwards, proposing a
wait at a dominating rate and keeping it with the ratio; the exact scheme inverts it in closed
form.
}
\end{frame}

\begin{frame}
  \frametitle{The compensator turns a path into unit-rate Poisson processes}
\begin{thm}[\citealp{Mey71dem}]
\label{thm.meyer1971}
 If no two components jump together, $\compensator$ is continuous and
 $\compensator_e(t) \to \infty$, then
 $\tau_e^j := \compensator_e(\arrivalTimes_{j}) - \compensator_e(\arrivalTimes_{j-1})$
 are independent $\mathrm{Exp}(1)$, over $j$ and $e$.
\end{thm}

No common jumps: what buys the joint independence
\note{
Rescaling each component's clock by its own compensator turns it into a unit-rate Poisson
process, and the time-changed processes are mutually independent. The univariate statement,
that each component separately is unit-rate Poisson, holds without the first hypothesis.
This is the goodness-of-fit test of the third part: if the path is a path of the model, the
rescaled inter-arrival times are independent $\mathrm{Exp}(1)$ draws.
}
\end{frame}

\begin{frame}
  \frametitle{A Hawkes process: every event raises the rate}
\begin{defi}
\label{def.hawkesprocess}
 $\intensity(t) = \baseIntensity_e
 + \sum_{\eone} \int_{[0,t)} \hawkesKernel\subscriptee(t-s)\,d\countingProc[\eone](s)$,
 with $\baseIntensity_e \geq 0$ and $\hawkesKernel\subscriptee \geq 0$.
\end{defi}

$\branchingMatrix\subscriptee = \int_0^\infty \hawkesKernel\subscriptee$: the branching
matrix

$\branchingRatio$: its spectral radius, the branching ratio
\note{
The baseline $\baseIntensity_e$ is the rate at which events of type $e$ arrive on their own
account, and each past event of type $\eone$ adds $\hawkesKernel\subscriptee$ of the time
elapsed since it. The half-open interval of integration is what makes the intensity
predictable.
$\branchingMatrix\subscriptee$ is the total excitation that one event of type $\eone$ exerts
on type $e$ over all future time. If some kernel is not integrable the branching ratio is
$+\infty$ by convention.
}
\end{frame}

\begin{frame}
  \frametitle{The exponential kernel carries the past in $\numEventTypes$ numbers}
\[
\begin{gathered}
 \hawkesKernel\subscriptee(t) = \excitation\subscriptee e^{-\decay t},
 \qquad
 \decayedCounts_e(t) = \sum_{j \, : \, \arrivalTimes_{j} < t} e^{-\decay(t - \arrivalTimes_{j})},
 \\
 \intensity[ ](t) = \baseIntensity + \excitation\decayedCounts(t)
\end{gathered}
\]

One decay $\decay$, shared by every pair

$\branchingMatrix = \excitation/\decay$: a count; $\excitation$: a rate
\note{
The decayed counts $\decayedCounts$ collect the whole past into one number per type, and the
intensity is affine in them. The strict inequality in the sum makes $\decayedCounts$
left-continuous, and therefore the intensity predictable.
The column sum of $\branchingMatrix$ is the expected number of direct offspring of one event;
the column sum of $\excitation$ is the jump that event produces in the total intensity,
measured per unit of time. They differ by $\decay$, and quoting them as one number is a
standard error.
}
\end{frame}

\begin{frame}
  \frametitle{The compensator is available in closed form}
\begin{prop}
\label{prop.compensatorClosedForm}
 Started at $\multiCountingProc(0) = 0$,
 \[
  \compensator_e(\timeHorizon) = \baseIntensity_e\timeHorizon
  + \sum_{\eone} \frac{\excitation\subscriptee}{\decay}
  \big( \countingProc[\eone](\timeHorizon-) - \decayedCounts_{\eone}(\timeHorizon) \big).
 \]
\end{prop}

The count read before $\timeHorizon$, the state at it

No numerical integration
\note{
The proof is Tonelli's theorem on the sum defining $\decayedCounts$: the integral of each
summand is $(1 - e^{-\decay(\timeHorizon - \arrivalTimes_j)})/\decay$, and there are
$\countingProc[\eone](\timeHorizon-)$ of them.
The map $\timeHorizon \mapsto \countingProc[\eone](\timeHorizon-) -
\decayedCounts_{\eone}(\timeHorizon)$ is continuous, since the two jumps cancel; the
post-jump reading $\countingProc[\eone](\timeHorizon) - \decayedCounts_{\eone}(\timeHorizon)$
is not the compensator, and overstates it by $\excitation\subscriptee/\decay$ at each arrival
of type $\eone$.
Now to notebook 04, sections 1 to 3: a Poisson process against the two-type process, and who
triggers whom.
}
\end{frame}

\begin{frame}
  \frametitle{The state is Markov}
\begin{thm}
\label{thm.markovState}
 $\decayedCounts$ is Markov, with generator
 \[
  \generatorL f(z) = -\decay\, z \cdot \nabla f(z)
  + \sum_{e} \big( \baseIntensity_e + (\excitation z)_e \big)
  \big( f(z + \unitVector_e) - f(z) \big).
 \]
\end{thm}

Nothing assumed about $\branchingRatio$

$O(1)$ per event, against $O(n^2)$ for the sum over the past
\note{
The flow is $z \mapsto e^{-\decay t}z$, the jump rate is the total intensity
$\mathbf{1}^{\transpose}(\baseIntensity + \excitation z)$, and a jump of type $e$ adds
$\unitVector_e$. The pair $(\multiCountingProc, \decayedCounts)$ is Markov too.
The integrability the generator needs holds on every finite horizon at every branching ratio:
the $k$-th convolution power of the exponential kernel carries $t^{k-1}/(k-1)!$.
A decay per pair would need one decayed count per pair, a state of dimension
$\numEventTypes^2$.
}
\end{frame}

\begin{frame}
  \frametitle{Stationary exactly when $\branchingRatio < 1$}
\begin{thm}[\citealp{BM96sta}]
\label{thm.stationarity}
 With $\baseIntensity > 0$: stationary if and only if $\branchingRatio < 1$, and then
 $\stationaryIntensity = (I - \branchingMatrix)^{-1}\baseIntensity$.
\end{thm}

$\branchingMatrix \geq 0$: $\branchingRatio$ an eigenvalue; irreducible $\Rightarrow$ $u, v > 0$, simple

$\totalRate = \mathbf{1}^{\transpose}\stationaryIntensity$,
$\bar{\baseIntensity} = \mathbf{1}^{\transpose}\baseIntensity$
\note{
In a stationary version the mean intensity is constant and satisfies
$\stationaryIntensity = \baseIntensity + \branchingMatrix\stationaryIntensity$; at
$\branchingRatio < 1$ the Neumann series inverts $I - \branchingMatrix$, with non-negative
entries.
The caption is Perron--Frobenius, parts i and ii: a non-negative matrix has its spectral
radius as an eigenvalue, with a right Perron vector $u$ and a left one $v$; under
irreducibility both are strictly positive and the eigenvalue is simple. We use $v$ for
supercritical growth and section 1.4 uses $u$.
$\totalRate$ is the total event rate and $\bar{\baseIntensity}$ the total immigration rate.
}
\end{frame}

\begin{frame}
  \frametitle{The mean cluster size counts the ancestor}
\begin{prop}
\label{prop.clusterSize}
 $C = \mathbf{1}^{\transpose}(I - \branchingMatrix)^{-1}$, and
 $\bar C = \sum_{\eone}\frac{\baseIntensity_{\eone}}{\bar{\baseIntensity}}C_{\eone}
 = \totalRate/\bar{\baseIntensity}$.
\end{prop}

Endogenous fraction: $1 - \bar{\baseIntensity}/\totalRate = 1 - 1/\bar C$

$\branchingRatio = 1 - 1/\bar C$ in particular when
$\mathbf{1}^{\transpose}\branchingMatrix = \branchingRatio\mathbf{1}^{\transpose}$
\note{
$C_{\eone}$ is the expected size of the cluster founded by an immigrant of type $\eone$,
counting the immigrant: the $k=0$ term of the Neumann series. Its strict descendants number
$C_{\eone} - 1$ on average.
$\bar{\baseIntensity}\,\bar C = \totalRate$: immigrants arrive at rate
$\bar{\baseIntensity}$, each founds a cluster of $\bar C$ events, and every event belongs to
exactly one cluster. It is the cheapest check an implementation admits.
In general $\branchingRatio$ is neither the endogenous fraction nor $1 - 1/\bar C$. Two
conditions are sufficient and neither is generic: constant column sums, and $\baseIntensity$

\begin{frame}

\label{prop.meanState}

\end{prop}

The generator with $f(z) = z$:
$\tfrac{d}{dt}\Expectation\decayedCounts = \baseIntensity
+ (\excitation - \decay I)\Expectation\decayedCounts$

Applying the generator to $f(z) = z$ gives a linear equation for the mean state; at
stationarity its derivative vanishes, which is the identity.

\begin{frame}
  \frametitle{$\excitation - \decay I$ is Hurwitz exactly when $\branchingRatio < 1$}
\begin{prop}
\label{prop.hurwitzCriterion}
 Let $\excitation \geq 0$ and $\decay > 0$. Then $\hurwitzMatrix := \excitation - \decay I$
 is Hurwitz if and only if $\branchingRatio < 1$.
\end{prop}

Eigenvalues of $\hurwitzMatrix$: $\decay(\gamma_i - 1)$, over those of $\branchingMatrix$
\note{
A matrix is Hurwitz when all of its eigenvalues have strictly negative real part; the solution
of $\dot x = \hurwitzMatrix x$ then decays from every start.
If $\branchingRatio < 1$, every real part is below one. Conversely, by Perron--Frobenius the
spectral radius is itself a real eigenvalue of $\branchingMatrix$, and that needs
$\excitation \geq 0$.
}
\end{frame}

\begin{frame}
  \frametitle{The stationary covariance solves a Lyapunov equation}
\begin{thm}
\label{thm.lyapunov}
 If $\branchingRatio < 1$ and $\baseIntensity > 0$, then $V := \CoVariance(\decayedCounts)$
 is the unique solution of
 $\hurwitzMatrix V + V\hurwitzMatrix^{\transpose} + \diag(\stationaryIntensity) = 0$,
 and $\CoVariance(\intensity[ ]) = \excitation V \excitation^{\transpose}$.
\end{thm}

$V = \int_0^\infty e^{\hurwitzMatrix s}\diag(\stationaryIntensity)
e^{\hurwitzMatrix^{\transpose}s}\,ds$, positive definite

Unit jumps, no common jumps: a diagonal source
\note{
The generator with $f(z) = zz^{\transpose}$: at an arrival of type $e$ the product
$\decayedCounts\decayedCounts^{\transpose}$ gains
$\decayedCounts\unitVector_e^{\transpose} + \unitVector_e\decayedCounts^{\transpose} +
\unitVector_e\unitVector_e^{\transpose}$. The last term is a unit because the jumps are unit
vectors, and diagonal because no two components jump together.
In practice the equation is one linear solve, in the $\numEventTypes(\numEventTypes+1)/2$
distinct entries of $V$.
}
\end{frame}

\begin{frame}
  \frametitle{The forward mean}
\begin{prop}
\label{prop.forwardMean}
 With $m_{s,t}(z) := \Expectation[\decayedCounts(t) \mid \decayedCounts(s+) = z]$,
 $\forecastHorizon = t - s$ and
 $\meanResponseIntegral(\forecastHorizon) := \int_{0}^{\forecastHorizon} e^{\hurwitzMatrix u}du$,
 \begin{gather*}
  m_{s,t}(z) = e^{\hurwitzMatrix \forecastHorizon}z
  + \meanResponseIntegral(\forecastHorizon)\,\baseIntensity, \\
  \Expectation\big[\multiCountingProc(t) - \multiCountingProc(s)
  \mid \decayedCounts(s+) = z\big]
  = \forecastHorizon\baseIntensity + \excitation\meanResponseIntegral(\forecastHorizon)z
  + \excitation\Big(\int_0^{\forecastHorizon}\meanResponseIntegral\Big)\baseIntensity .
 \end{gather*}
\end{prop}

Finite at every $\branchingRatio$, on every horizon; a function of $t - s$ alone
\note{
The pair $(\multiCountingProc, \decayedCounts)$ is Markov and its generator does not depend on
time, so given the past up to $s$ only the state $\decayedCounts(s+)$ and the elapsed time matter.
The generator with $f(z) = z$ gives
$\partial_t m_{s,t} = \hurwitzMatrix m_{s,t} + \baseIntensity$ with $m_{s,t}(z) \to z$ as
$t \downarrow s$, and variation of constants gives the first display; the compensator integrates
the intensity, which gives the second.
This is the equation the forecast of section 1.4 is a contraction of.
If $\branchingRatio < 1$, then
$\meanResponseIntegral(\forecastHorizon) = \hurwitzMatrix^{-1}(e^{\hurwitzMatrix
\forecastHorizon} - I)$. The transient mean $m_{s,t}(z)$ is not the stationary mean $m$: the two
meet at the fixed point of the same equation.
}
\end{frame}

\begin{frame}
  \frametitle{In deviations from $m$, the state forgets at the rate of
  $e^{\hurwitzMatrix \forecastHorizon}$}
\begin{gather*}
 m_{s,t}(z) - m = e^{\hurwitzMatrix \forecastHorizon}(z - m), \\
 \Expectation\big[\multiCountingProc(t) - \multiCountingProc(s)
 \mid \decayedCounts(s+) = z\big]
 = \forecastHorizon\,\stationaryIntensity
 + \excitation\meanResponseIntegral(\forecastHorizon)(z - m)
\end{gather*}

$\branchingRatio < 1$: the baseline enters only through $m$, and $m_{s,t}(z) \to m$ as
$t \to \infty$

$z = m$: nothing to forget
\note{
Both follow from the previous frame when $\branchingRatio < 1$. The first from
$\meanResponseIntegral(\forecastHorizon)\baseIntensity
= (I - e^{\hurwitzMatrix \forecastHorizon})m$, since
$\hurwitzMatrix m = -\baseIntensity$. The second from
$\excitation(\int_0^{\forecastHorizon}\meanResponseIntegral)\baseIntensity
= \forecastHorizon\excitation m - \excitation\meanResponseIntegral(\forecastHorizon)m$ and
$\baseIntensity + \excitation m = \stationaryIntensity$.
The expected count is the stationary rate over the horizon, corrected by the excess of the
state over its mean. A state at its mean forecasts the stationary rate, at every horizon.
}
\end{frame}

\begin{frame}
  \frametitle{One extra event: the mean response}
\begin{corol}
\label{corol.meanResponse}
 One more event of type $\eone$ in the state displaces the mean state $\forecastHorizon$ later
 by $R_{\eone}(\forecastHorizon) = e^{\hurwitzMatrix \forecastHorizon}\unitVector_{\eone}$,
 whatever the state, and
 $\int_0^\infty \mathbf{1}^{\transpose}\excitation R_{\eone}(\forecastHorizon)
 \,d\forecastHorizon = C_{\eone} - 1$.
\end{corol}

Rates $\decay(1 - \Real\gamma_i)$; the slowest $\decay(1 - \branchingRatio)$
\note{
The response is $m_{s,s+\forecastHorizon}(z + \unitVector_{\eone})
- m_{s,s+\forecastHorizon}(z)$: the two means differ only through the state at $s$, and the term
in $\baseIntensity$ cancels in the difference. When $\branchingMatrix$ is diagonalisable the response is a combination of
exponentials at the rates $\decay(1 - \Real\gamma_i)$; in general the modes carry polynomial
factors as well.
The integrated response of the total intensity is the expected number of strict descendants of
the extra event, $C_{\eone} - 1$: the event itself sits in the state and not in the count.
}
\end{frame}

\begin{frame}
  \frametitle{Thinning: propose at the bound, keep with the ratio}
{\footnotesize
\begin{algorithmic}
 \REQUIRE $(\arrivalTimes[ ]_i, \event[i])_{i=1,\dots,n-1}$
 \STATE set $t := \arrivalTimes[ ]_{n-1}$ and $\bar{\lambda} := \totalIntensity(\arrivalTimes[ ]_{n-1}+)$
 \STATE set $\xi := 0$
 \WHILE{$\xi = 0$}
 \STATE draw $U \sim \mathrm{Exp}(\bar{\lambda})$
 \STATE set $\xi := 1$ with probability $\totalIntensity(t+U)/\bar{\lambda}$
 \STATE update $t \leftarrow t+U$ and $\bar{\lambda} \leftarrow \totalIntensity(t)$
 \ENDWHILE
 \STATE set $\arrivalTimes[ ]_n := t$
 \STATE draw $\event[n]$ with probabilities proportional to
        $\intensity[1](\arrivalTimes[ ]_n), \dots,
        \intensity[\numEventTypes](\arrivalTimes[ ]_n)$
 \RETURN $(\arrivalTimes[ ]_n, \event[n])$
\end{algorithmic}
}

$\excitation \geq 0$: $\totalIntensity$ non-increasing between events, so the bound is free
\note{
Ogata's algorithm, for any kernel. If the ground intensity were constant the next wait would be
exponential; it is not, but between events it only decays, so its value just after the last
event dominates it. Draw at the dominating rate and keep the candidate with the ratio of the
true rate to the bound.
The dominating value is the \emph{post}-jump one: $\decayedCounts$ is left-continuous, so the
pre-jump value is smaller by the jump and does not dominate.
The rejected candidates are work done and discarded. How many are rejected depends on how far
the intensity decays during a wait, and the notebook measures it.
}
\end{frame}

\begin{frame}
  \frametitle{The state is carried from event to event, not recomputed}
\[
 \decayedCounts(\arrivalTimes[ ]_{n+1})
 = \big( \decayedCounts(\arrivalTimes[ ]_{n}) + \unitVector_{\event[n]} \big)
 \, e^{-\decay(\arrivalTimes[ ]_{n+1} - \arrivalTimes[ ]_{n})}
\]

$O(1)$ per event, against $O(n^2)$ for the direct sum

Pre-jump: enters the intensity. Post-jump: carried forward.
\note{
For the exponential kernel each of the three evaluations of $\totalIntensity$ in thinning reads
$\decayedCounts$ instead of the history: $\totalIntensity = \mathbf{1}^{\transpose}
(\baseIntensity + \excitation\decayedCounts)$, and the algorithm holds $\numEventTypes$ numbers

The two values in the recursion are different objects and both are needed. Confusing them
shifts every intensity by one event, and produces a path that is plausible and wrong.
}

\begin{frame}
  \frametitle{A common decay makes the survival function a product}
\[
 \Prob\big( \arrivalTimes[ ]_{n+1} - \arrivalTimes[ ]_{n} > s \,\big|\,
 \filtrationF_{\arrivalTimes[ ]_{n}} \big)
 = e^{-\bar{\baseIntensity}s} \cdot
 \exp\Big( -\frac{D}{\decay}\big(1 - e^{-\decay s}\big) \Big)
\]

$D := \totalIntensity(\arrivalTimes[ ]_{n}+) - \bar{\baseIntensity} \geq 0$

A minimum of two independent clocks: immigration and excitation
\note{
Between events every component of $\decayedCounts$ decays by the same factor, because $\decay$
is common to all pairs; hence so does the excited part of $\totalIntensity$, which is
$D e^{-\decay(t - \arrivalTimes[ ]_n)}$. Substituting into the conditional survival function
and integrating gives the product.
Non-negativity of $\excitation$ enters separately, and gives $D \geq 0$.

\begin{frame}
  \frametitle{The excitation clock is defective}
\begin{thm}[\citealp{DZ13exa}]
\label{thm.dassiosZhao}
 With $U_1, U_2$ independent uniforms, the next wait is $\tau_1 \wedge \tau_2$:
 \[
  \tau_1 = -\frac{\log U_1}{\bar{\baseIntensity}},
  \qquad
  \tau_2 = -\frac{1}{\decay}\log\Big(1 + \frac{\decay\log U_2}{D}\Big),
 \]
 and $\tau_2 = +\infty$ when the argument is not positive.
\end{thm}

$\Prob(\tau_2 = \infty) = e^{-D/\decay}$: the next event an immigrant

The type drawn before the jump, with probabilities $\intensity/\totalIntensity$
\note{
The excited factor carries the finite total mass $D/\decay$, the expected number of direct
offspring the current state still owes. With probability $e^{-D/\decay}$ it expires without
firing. That is not a numerical edge case: an implementation that clips $\tau_2$ biases the
immigrant share.
The wait sees $\excitation$ only through $\mathbf{1}^{\transpose}\excitation$, so it is the
type draw that makes the scheme multivariate, and it is there that the full matrix re-enters.
}
\end{frame}

\begin{frame}
  \frametitle{The exact scheme rejects nothing}
{\footnotesize
\begin{algorithmic}
 \REQUIRE $\arrivalTimes[ ]_{n}$ and the post-jump state $\decayedCounts(\arrivalTimes[ ]_n+)$
 \STATE set $D := \mathbf{1}^{\transpose}\excitation\decayedCounts(\arrivalTimes[ ]_n+)$
 \STATE draw $U_1, U_2$ independent and uniform on $(0,1)$
 \STATE set $\tau_1 := -\log U_1 / \bar{\baseIntensity}$
 \IF{$D > 0$ and $1 + \decay\log U_2/D > 0$}
 \STATE set $\tau_2 := -\decay^{-1}\log(1 + \decay\log U_2/D)$
 \ELSE
 \STATE set $\tau_2 := +\infty$
 \ENDIF
 \STATE set $\arrivalTimes[ ]_{n+1} := \arrivalTimes[ ]_{n} + \tau_1 \wedge \tau_2$
 \STATE set $\decayedCounts(\arrivalTimes[ ]_{n+1}) := \decayedCounts(\arrivalTimes[ ]_{n}+)
        \, e^{-\decay(\arrivalTimes[ ]_{n+1} - \arrivalTimes[ ]_{n})}$
 \STATE draw $\event[n+1]$ with probabilities
        $\intensity(\arrivalTimes[ ]_{n+1})/\totalIntensity(\arrivalTimes[ ]_{n+1})$
 \STATE set $\decayedCounts(\arrivalTimes[ ]_{n+1}+) := \decayedCounts(\arrivalTimes[ ]_{n+1})
        + \unitVector_{\event[n+1]}$
 \RETURN $(\arrivalTimes[ ]_{n+1}, \event[n+1])$
\end{algorithmic}
}
\note{
Nothing in the algorithm is approximate and nothing is rejected, at $O(1)$ per event.
It needs $\excitation \geq 0$, a common $\decay$ and $\bar{\baseIntensity} > 0$, and nothing
about the branching ratio, which is why the notebook can run it above criticality.

Band: pointwise, from the order statistics of a uniform sample

A wrong kernel bends the line
\note{
The $k$-th of $n$ order statistics of a uniform sample is $\mathrm{Beta}(k, n-k+1)$, and
$-\log(1-u)$ carries it to the exponential; that gives an exact pointwise band, which widens
in the tail. The notebook adds the simultaneous band of the Kolmogorov--Smirnov statistic.
A transposed kernel or a wrong decay in the compensator bends the plot visibly. Reading the
compensator post-jump does not: it shifts $\compensator_e$ by the constant
$\branchingMatrix_{e,e}$ at every arrival of type $e$, and moves only the first residual of
each type.
