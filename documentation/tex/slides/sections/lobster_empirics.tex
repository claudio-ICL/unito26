\pause

A result on generated flow: a result about the generator

\pause

Four absences, and what recorded data settles
\note{
The apparatus of sections 1.3 and 1.4 is developed on flow that we generate, and a result
obtained on generated flow is a result about the generator. Four things are absent from the
generated setting by construction, and each of them bounds what can be asked of it. Recorded
data is what settles the questions it cannot.
}
\end{frame}

\begin{frame}
  \frametitle{The intensities do not read the book}
\[
 \queueImbalance[1]_t
 = \frac{\nthBestBidSize[1]_t - \nthBestAskSize[1]_t}{\nthBestBidSize[1]_t + \nthBestAskSize[1]_t}
\]

\pause

No queue-depletion feedback, and no adverse selection

\pause

A traded book: depletion begets depletion
\note{
The arrival rates are indifferent to whether a queue is about to empty; only the marks see the
book. There is in particular no informed trading. In a traded market part of the flow is
informed, and a resting limit order is then short an option: it is filled when someone wishes
to trade against it, which is disproportionately when trading against it is right, and the
defence available to whoever posted it is to withdraw first.
A queue about to be picked off is therefore a queue whose own side pulls away from it. That is
what makes the imbalance at the touch informative in a traded book: a thin bid is thin because
those posting on that side inferred something. A kernel built for replenishment does the
reverse, and the two cannot both be strong in one specification.
}
\end{frame}

\pause

A dropped withdrawal: a thinned process, not the Hawkes one
\note{
The definition of the order flow asks the sizes to be independent of the arrival times and of
the types, and the short-horizon forecast uses that. A generator whose withdrawals draw against
the size actually resting, or which drops a withdrawal on an empty side, emits a thinned
process rather than the Hawkes process it started from.
There is a single excitation timescale, the kernel being one exponential; there is no intraday
non-stationarity; and there is no anchor for the price level, so the level wanders.
}
\end{frame}

\begin{frame}
  \frametitle{Read the comparison asymmetrically}
\begin{remark}
\label{remark.asymmetricReading}
 On generated flow, a result favourable to $\queueImbalance[1]$ is the stronger finding.
\end{remark}

\pause

In a traded market: whether $\signedExcitation$ carries either sign

\pause

And at which window and horizon the sign can be read
\note{
Whatever forecasting power $\queueImbalance[1]$ retains in the generated setting is
mechanical: a depleted queue is one market order from clearing, and clearing moves the mid.
None of it is informational. A result favourable to $\OFI$ is therefore not evidence that it
dominates $\queueImbalance[1]$ in a traded market.
Recorded data settles what the generated setting cannot: whether the signed excitation of the
last hour carries either sign in a traded market, and over what window and what horizon the
sign of the forecast can be read from the order flow imbalance at all. That is the assignment
of the chapter, set in section 1.5 of the notes: build the session from the LOBSTER pair,
compute the two statistics, regress, and read the sign across a grid of windows and horizons.
}
\end{frame}
