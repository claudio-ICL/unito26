The basic theory of stochastic processes is assumed:
filtrations, conditional expectation, martingales and stopping times.
The lecture notes of a first course on the subject suffice,
and \cite{Wil91pro} is the classical textbook reference.

The course also assumes a machine set up for development,
on which Python code and Jupyter notebooks can be read, written and run.
A student who has no such setup and does not know how to arrange one
should write to the lecturer.
