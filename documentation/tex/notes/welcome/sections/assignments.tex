There are two optional assignments, one for each chapter.
The first is Section \ref{sec.lobsterEmpirics}:
it takes the order flow imbalance of Section \ref{sec.priceFormation} to recorded data,
and asks what it accounts for and what it forecasts.
The second belongs to Chapter \ref{chap.options} and is published with it.

An assignment is submitted as a pull request into the course repository.
The work is written on a branch,
the tests are run,
the pull request is opened against the main branch,
and the continuous-integration workflow runs the tests again on it;
the submission is complete when that workflow has passed and the pull request stands open.
The repository states what a pull request must contain and by when.
Code reaches anyone who will rely on it by that route,
and an assignment is marked on it as well as on its analysis.
